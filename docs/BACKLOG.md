# Бэклог AppShelf: обратная связь и продвижение

Разбор промпта «бесплатная система публикации и обратной связи» от 31.10.2026.
Расходы во всех пунктах нулевые: только GitHub Actions на стандартных раннерах и бесплатный бот Telegram.

## Сделано

| Задача | Что входит |
| --- | --- |
| Issues → Telegram | Workflow на открытие и переоткрытие Issue, сообщение в один чат через бота. Инструкция `docs/FEEDBACK_AUTOMATION.md`. |
| Формы Issues и ссылки в README | Формы «Предложить функцию» и «Вопрос» к имеющейся форме ошибки; раздел обратной связи в `README.md` и `README.ru.md`. |
| Ссылки в программе | «Сообщить об ошибке» и «Оценить в Microsoft Store» в параметрах программы. Меню папок не трогаем. |
| Сайт на GitHub Pages (en, ru), 01.11.2026 | Страницы в `site/`, картинки и промо из Store-медиа (`tools/site/assets.py`). Английская страница при первом визите уводит на русскую по языку браузера, переключатель запоминает выбор. Публикует `.github/workflows/site.yml`; выключен до выхода в Store: включить Pages (Source: GitHub Actions) и переменную `SITE_ENABLED = true`. |

## Позже

| Задача | Когда браться | Заметки |
| --- | --- | --- |
| Отзывы Microsoft Store → Telegram | Когда программа опубликована и пришли первые отзывы | Официальный API `Get app reviews` (у нас MSIX, он подходит). Нужно связать приложение Microsoft Entra с аккаунтом Partner Center; для личного аккаунта разработчика проверить, как это сделать. Проверка раз в день, а не раз в час: отзывов будет немного. Оценки 1–3 отдельным сообщением, 4–5 в дневной сводке. |
| Защита от отключения расписания | Вместе с отзывами | GitHub отключает запуски по расписанию после 60 дней без активности в публичном репозитории. Нужна понятная инструкция, как это заметить и включить обратно, без искусственных коммитов. |
| Еженедельная сводка | Если отзывов и Issues станет заметно больше | Только счётчики и ссылки, без «тем». |
| GitHub Discussions | Решение пользователя | Включаются в настройках репозитория вручную. |

## Отказались

| Что | Почему |
| --- | --- |
| Немецкий и другие языки сайта | Программа умеет только английский и русский; сайт обещал бы то, чего нет. |
| «Повторяющиеся темы» по ключевым словам | На единицах отзывов это шум, а не аналитика. |
| Проверка отзывов каждый час, учёт правок отзывов, служебная ветка с состоянием | Сложность ради случаев, которых пока нет. Вернуться, если отзывов станет много. |
| Импорт CSV из Partner Center | Обходной путь для программ без MSIX; у AppShelf MSIX. |
| Автоматическое создание Issues из отзывов | Отзывы остаются уведомлениями; ошибку из отзыва переносим в Issue вручную. |
