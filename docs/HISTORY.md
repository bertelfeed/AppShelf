# Reconstructed development history

The Git repository begins with five development checkpoints. The project was
originally developed locally without Git. These commits were reconstructed from
actual source backups and edit history, rather than fabricated empty commits or
decompiled release binaries. Their commit dates are reconstruction dates.

| Checkpoint | Public version | Contents |
| --- | --- | --- |
| Initial implementation | 0.2.0 | Nested folders, Fluent editor, independent folder options, desktop/taskbar menus and surface scales. |
| Shell and appearance | 0.3.0 | Dedicated input-hook thread, refreshed icons, Mica/acrylic, custom folder artwork and taskbar previews. |
| Desktop organization | 0.4.0 | MCP server, reversible shortcut organization, copied launchers and automatic shortcut repair. |
| Menu interaction | 0.5.0 | Paging, drag and drop, insertion indicators and nested back navigation. |
| Current preview | 0.6.0 | English/Russian localization, current artwork and input refinements, centralized versioning, MIT license, public documentation, screenshots and release automation. |

The first four source states were recovered into isolated directories and built
successfully with no compiler warnings. The current state receives the full
checks and packaging verification. Old internal build numbers were not public
release numbers; they are consolidated into the preview versions above.

Unchanged files come from the surviving checkout; edited files come from source
history, including a cross-session backup of the shortcut publisher. Solution,
build metadata and checkpoint descriptions were normalized for standalone builds.
This is a curated, reproducible history, not a claim that old Git commit IDs were
recovered. Personal session logs, profile data and machine paths are not published.

The first stable release will be **1.0**. Version **0.6.1** is a development preview.
