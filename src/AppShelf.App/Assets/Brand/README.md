# Service link artwork

Downloaded from the owners' official brand resources on 29 October 2026:

- Microsoft Store English: https://get.microsoft.com/images/en-us%20dark.svg
- Microsoft Store Russian: https://get.microsoft.com/images/ru%20dark.svg
- Badge documentation: https://github.com/microsoft/app-store-badge
- GitHub logo archive: https://brand.github.com/GitHub_Logos.zip
  (`GitHub Logos/PNG/GitHub_Lockup_White.png` and its SVG source)
- GitHub usage guidelines: https://brand.github.com/foundations/logo

The Store PNGs are unchanged 4x raster exports of the supplied SVGs (644 × 176),
rendered with sharp/libvips. GitHub's PNG and SVG are the original downloads.
Only PNGs are embedded in the WPF assembly; the app never fetches artwork over
the network. The Store image follows the selected interface language.

Microsoft provides the complete Store badge. GitHub provides the logo lockup;
its surrounding dark button is AppShelf UI. Both controls are 161 × 44 device
independent units, with hover, pressed, disabled and keyboard-focus states.

These are third-party brand assets, outside AppShelf's MIT license. See the
repository's `THIRD-PARTY-NOTICES.txt` for attribution and source links.
