# AppShelf privacy policy

[Русская версия](#политика-конфиденциальности-appshelf)

Effective November 1, 2026.

AppShelf has no accounts, analytics, telemetry or ads. The developer receives no data
from the app.

**What stays on your PC.** Your folders, settings, copies of the shortcuts you add and
the images you pick for folder icons are kept in the AppShelf profile on your PC. The
Microsoft Store version keeps it in the app's own LocalState folder; the ZIP version
keeps it in the `data` folder beside the program. Uninstalling the Store version
removes this profile. Removing an item from AppShelf never removes the app itself.

**Update check.** Unless you turn off Settings → Check for updates, AppShelf checks
for a newer version a minute after start and then once a day. The Microsoft Store
version asks Microsoft Store through Windows; the ZIP version asks GitHub for the
latest release of this project. Like any web request, it shows your IP address to
Microsoft or GitHub. Nothing about you or your folders is sent, and nothing is
downloaded automatically.

**Links.** The Store, GitHub and Boosty pages open in your browser only when you
click them.

**Optional MCP server.** If you connect an MCP client, such as Claude, to AppShelf,
that client can read the names of your apps and of the files on your desktop, and
change your folders. The server runs only on your PC; the client and its service are
governed by their own privacy policies. AppShelf itself never contacts an AI service.

**Purchases** are handled by Microsoft Store under Microsoft's privacy statement.

**Questions:** [GitHub Issues](https://github.com/bertelfeed/AppShelf/issues).
Changes to this policy are published in this file.

# Политика конфиденциальности AppShelf

Действует с 1 ноября 2026 года.

В AppShelf нет аккаунтов, аналитики, телеметрии и рекламы. Разработчик не получает от
приложения никаких данных.

**Что остаётся на компьютере.** Папки, настройки, копии добавленных ярлыков и
картинки для значков папок хранятся в профиле AppShelf на вашем компьютере. Версия из
Microsoft Store держит его в собственной папке LocalState, ZIP-версия — в папке `data`
рядом с программой. При удалении версии из Store профиль удаляется вместе с ней.
Удаление элемента из AppShelf никогда не удаляет само приложение.

**Проверка обновлений.** Если не выключить **Параметры → Проверять обновления**,
AppShelf через минуту после запуска и дальше раз в сутки проверяет, нет ли новой
версии. Версия из Store спрашивает Microsoft Store через Windows, ZIP-версия — последний
релиз проекта на GitHub. Как любой запрос в интернет, он показывает Microsoft или
GitHub ваш IP-адрес. Никаких сведений о вас и ваших папках не передаётся, и сама
проверка ничего не скачивает.

**Ссылки.** Страницы Store, GitHub и Boosty открываются в браузере, только когда вы
на них нажимаете.

**MCP-сервер по желанию.** Если подключить к AppShelf MCP-клиент, например Claude,
клиент сможет читать названия ваших приложений и файлов на рабочем столе и менять
папки. Сервер работает только на вашем компьютере, а на клиент и его сервис
распространяются их собственные политики. Сам AppShelf к ИИ-сервисам не обращается.

**Покупки** проводит Microsoft Store по заявлению о конфиденциальности Microsoft.

**Вопросы:** [GitHub Issues](https://github.com/bertelfeed/AppShelf/issues).
Изменения этой политики публикуются в этом файле.
